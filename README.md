# Математик 7 — Багшийн туслах 🧮

Даланзадгад сумын 5-р сургууль · 7-р ангийн сурагчдын математикийн хоцрогдлыг нөхөх вэб апп.

## Апп юу хийдэг вэ?

1. Сурагч **овог нэр, ангиа** оруулна.
2. **Бүлэг** сонгоно (8 бүлэг).
3. Бүлгээс **ээлжит сэдэв** сонгоно (нийт 30 сэдэв).
4. Сонгосон сэдвээр **5 бодлого нэг нэгээр** гарна. Тоонууд нь санамсаргүйгээр үүсдэг тул сурагч бүр, оролдлого бүрт өөр бодлого гарна.
5. Бодлого бүрийн дараа:
   - ✅/❌ зөв эсэх, зөв хариу
   - 🔍 **Алдаагаа олъё** — сурагчийн хариунаас түгээмэл алдааг танина (жишээ нь: «хуваарийг нэмсэн», «тэмдгийн алдаа», «үйлдлийн дараалал»)
   - 📝 **Хэрхэн бодох вэ?** — тухайн бодлогын тоогоор алхам алхмаар бодолт
   - 🎯 Зөвлөгөө
   - 🤖 (заавал биш) **AI багшаас тайлбар** — Claude AI сурагчийн хариуг харж, хувь хүнд тохирсон тайлбар болон дасгал бодлого өгнө
6. 5 бодлого дууссаны дараа сурагчид **оноо, хувь, хугацаа, анхаарах зүйл** гарна.
7. Үр дүн автоматаар **багшийн Google Sheet**-д бичигдэнэ.

| Бүлэг | Сэдвүүд |
|---|---|
| I. Рационал тоо | Эерэг/сөрөг тоо нэмэх хасах · Бутархай нэмэх хасах · Бутархай үржих хуваах · Үйлдлийн дараалал ба зэрэг · Аравтын бутархай |
| II. Алгебрын илэрхийлэл | Утга олох · Төсөөтэй гишүүд · Хаалт задлах |
| III. Шугаман тэгшитгэл | ax + b = c · Хоёр талдаа x-тэй · Хаалттай · Тэгшитгэл зохиож бодох |
| IV. Харьцаа, пропорц, хувь | Харьцаагаар хуваах · Пропорц · Тооны хувь · Хямдрал/өсөлт · Шууд ба урвуу хамаарал |
| V. Өнцөг ба гурвалжин | Хөрш, босоо өнцөг · Гурвалжны өнцөг · Параллель шулуун |
| VI. Тойрог, талбай, эзлэхүүн | Тойргийн урт · Дугуйн талбай · Гурвалжин/трапецын талбай · Эзлэхүүн |
| VII. Статистик ба магадлал | Дундаж · Медиан, моод · Магадлал |
| VIII. Координат ба функц | Координатын мөч · Шугаман функцийн утга · Цэг график дээр орших эсэх |

## Багшид: суулгах заавар (≈10 минут)

### Алхам 1. Google Sheet бэлдэх

1. [sheets.new](https://sheets.new) хаягаар шинэ Google Sheet үүсгэж, нэр өгнө (жишээ: «Математик 7 — Үр дүн»).
2. Цэснээс **Extensions → Apps Script** дарна.
3. Нээгдсэн `Code.gs` файлын агуулгыг бүгдийг устгаад, энэ репогийн [apps-script/Code.gs](apps-script/Code.gs) файлын кодыг хуулж тавина. 💾 Хадгална.
4. Дээд талын функц сонгогчоос **`setup`**-ийг сонгоод **Run** дарна. Анх удаа зөвшөөрөл асууна → өөрийн Google бүртгэлээ сонгож **Allow** дарна.
   - Sheet дээр **Нэгтгэл**, **Дэлгэрэнгүй**, **Тайлан** гэсэн 3 хуудас үүснэ.

### Алхам 2. Web app болгон нийтлэх

1. Apps Script дээр **Deploy → New deployment** дарна.
2. ⚙️ дүрс → **Web app** сонгоно.
3. **Execute as: Me**, **Who has access: Anyone** гэж тохируулна.
4. **Deploy** → гарч ирэх **Web app URL**-ийг (`https://script.google.com/macros/s/.../exec`) хуулна.

### Алхам 3. Апп-д холбох

[js/config.js](js/config.js) файлыг нээж `SCRIPT_URL`-д хуулсан URL-аа тавина:

```js
SCRIPT_URL: 'https://script.google.com/macros/s/AKfycb..../exec',
```

Ангийнхаа жагсаалтыг `CLASSES`-д засаж болно.

### Алхам 4. Сурагчдад түгээх

**GitHub Pages ашиглах (санал болгож байна):** GitHub дээр репо → **Settings → Pages** → Branch: `main`, folder: `/ (root)` → Save.
Хэдэн минутын дараа `https://<таны-нэр>.github.io/Umnugovi-Dalanzadgad-school-5/` хаяг гарна. Энэ холбоосыг (эсвэл QR кодыг) сурагчдад өгнө.

Компьютерийн өрөөнд интернэтгүй үед `index.html`-ийг шууд хөтчөөр нээж болно — үр дүн тухайн компьютерт хадгалагдаад, интернэт орж ирэхэд автоматаар илгээгдэнэ.

### Алхам 5 (заавал биш). Claude AI тайлбар идэвхжүүлэх

1. [console.anthropic.com](https://console.anthropic.com) дээр API түлхүүр (`sk-ant-...`) авна.
2. Apps Script → ⚙️ **Project Settings** → **Script Properties** → **Add script property**:
   - Property: `ANTHROPIC_API_KEY`, Value: `sk-ant-...`
3. Шалгах: функц сонгогчоос `testAI`-г сонгоод **Run** → **Execution log** дээр монгол тайлбар гарвал болно.

API түлхүүр зөвхөн Google сервер дээр хадгалагдах тул сурагчдад харагдахгүй. AI тайлбар бүр бага хэмжээний төлбөртэй. Зардлыг хянахын тулд минутанд 40 хүсэлтээс илүүг хүлээж авахгүй (`AI_MAX_PER_MINUTE`). AI ашиглахгүй бол [js/config.js](js/config.js)-д `AI_ENABLED: false` гэж тохируулна. Ингэсэн ч бодлого бүрийн алхам алхмаар тайлбар хэвээр ажиллана.

> ⚠️ `Code.gs`-ийг өөрчилсний дараа **Deploy → Manage deployments → ✏️ → Version: New version → Deploy** хийхгүй бол өөрчлөлт ажиллахгүй.

## Багш Sheet-ээс юу харах вэ?

| Хуудас | Агуулга |
|---|---|
| **Нэгтгэл** | Нэг мөр = нэг сурагчийн нэг сэдэв: огноо, нэр, анги, бүлэг, сэдэв, зөв тоо, хувь, хугацаа, Б1–Б5 (1 = зөв, 0 = буруу), AI ашигласан тоо, алдааны төрлүүд |
| **Дэлгэрэнгүй** | Нэг мөр = нэг бодлого: бодлогын текст, сурагчийн хариу, зөв хариу, зөв эсэх, зарцуулсан хугацаа, **алдааны төрөл** |
| **Тайлан** | Автоматаар шинэчлэгдэнэ: ① анги × сэдвээр дундаж хувь (сул сэдэв дээрээ гарна), ② хамгийн түгээмэл алдаанууд, ③ сурагч бүрийн дундаж |

💡 **Дэлгэрэнгүй** хуудсанд **Data → Create a filter** хийж, анги эсвэл сэдвээр шүүвэл хоцрогдолтой сурагчдыг хурдан олно.

## Шинэ сэдэв, бодлого нэмэх

[js/curriculum.js](js/curriculum.js) файлд бүлэг бүрийн `topics` массив байгаа. Шинэ сэдэв нэмэхдээ:

```js
{
  id: 'my-topic', title: 'Миний шинэ сэдэв',
  gen() {
    const a = R(2, 9), b = R(2, 9);          // санамсаргүй тоо
    return {
      text: `${a} · ${b} = ?`,               // бодлого
      type: 'number', answer: a * b,          // 'number' | 'expr' | 'choice'
      hint: 'Хариугаа тоогоор бичнэ үү',
      steps: [`${a}-г ${b} удаа нэмнэ`, `Хариу: <b>${a * b}</b>`],
      tip: 'Үржүүлэх хүснэгтээ давтаарай.',
      mistakes: [{ v: a + b, tag: 'Нэмсэн', msg: 'Үржүүлэхийн оронд нэмчихжээ.' }],
    };
  },
},
```

Сурагч хариугаа `3,5` / `3.5` / `-3/4` / `3x + 5` / `3х + 5` (кирилл х) хэлбэрээр бичихэд бүгдийг зөв танина.
